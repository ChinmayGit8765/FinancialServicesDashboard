<critical_research_findings>
- pgvector extension needs SUPERUSER. App user `quantlens` cannot CREATE EXTENSION. Put it in docker/db/00-init.sql (runs as postgres superuser via /docker-entrypoint-initdb.d). Flyway handles relational DDL only. (RESEARCH Pitfall 1)
- BigDecimal money: never `new BigDecimal(double)`. Use `BigDecimal.valueOf(d).setScale(6, RoundingMode.HALF_UP)`. NUMERIC(18,6) columns. (RESEARCH Pitfall 6)
- GBM Ito correction `(mu - sigma^2/2)*dt` MUST be present, golden test E[S(T)] ≈ S(0)*exp(mu*T). (RESEARCH Pitfall 7)
- Idempotence: guard on a seed_log completed flag set at END of the @Transactional run, not just count()>0 (RESEARCH Open Question 3).
- Fixed RNG seed 42 via Hipparchus MersenneTwister; correlated draws via shared market factor + per-security beta + idiosyncratic. (RESEARCH Pattern 6, Don't Hand-Roll table)
- Inject the @Bean PasswordEncoder into the seeder; do NOT `new BCryptPasswordEncoder()` inside the seeder (strength mismatch risk — RESEARCH Anti-Patterns).
</critical_research_findings>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app user → database | `quantlens` app user runs Flyway DDL (relational + vector_store table, not extensions) |
| seed data → persistence | Generated values written to NUMERIC columns; no external/untrusted input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03 | Elevation of privilege | CREATE EXTENSION as app user | mitigate | Extension creation runs as postgres superuser in docker/db/00-init.sql; app user runs relational + vector_store table DDL only — never CREATE EXTENSION in Flyway (RESEARCH Pitfall 1) |
| T-01-04 | Information disclosure | Demo password storage | mitigate | Passwords BCrypt-hashed via the single injected PasswordEncoder bean; never plaintext; demo1234 is intentionally public for the demo |
| T-01-05 | Tampering | Partial seed leaving inconsistent state | mitigate | Single @Transactional run + seed_log completed flag set at end; a half-finished seed rolls back and re-runs (RESEARCH Open Question 3) |
| T-01-SC | Tampering | Hipparchus dependency add | mitigate | hipparchus-core/hipparchus-stat 4.0.3 are STACK.md-locked, Maven Central, active maintainer (same team as Apache Commons Math); pinned exact version |
</threat_model>
