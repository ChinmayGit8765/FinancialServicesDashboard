<critical_research_findings>
- Spring Security default form login returns 302 redirects → breaks the SPA. Override successHandler → 200 JSON {"authenticated":true,"username":...}; failureHandler → 401 JSON. loginProcessingUrl=/api/auth/login. (RESEARCH Pattern 4, Pitfall 4)
- Session: SessionCreationPolicy.ALWAYS + sessionFixation().changeSessionId() (security best practice). (RESEARCH Pattern 4, Security Domain V3)
- CSRF: CookieCsrfTokenRepository.withHttpOnlyFalse() so Axios can read XSRF-TOKEN and send X-XSRF-TOKEN (RESEARCH Pattern 4 + Open Question 2 recommendation). The Axios interceptor lives in the frontend (Plan 04).
- permitAll on /api/auth/login, /api/auth/personas, /actuator/health; everyRequest authenticated. (RESEARCH Pattern 4)
- Session tracking is cookie-only (no JSESSIONID in URL) — Security Domain V3.
</critical_research_findings>

## Trust Boundaries

| session cookie → portfolio scope | Cookie identity determines which persona's portfolio is returned |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Spoofing | /api/auth/login credential check | mitigate | BCrypt verification via the shared PasswordEncoder + JPA UserDetailsService; failure returns 401 with a generic message (no user-enumeration detail) |
| T-01-07 | Elevation of privilege | Session fixation after login | mitigate | sessionFixation().changeSessionId() rotates the session id on authentication success (RESEARCH Security Domain V3) |
| T-01-08 | Spoofing | CSRF on state-changing endpoints | mitigate | CookieCsrfTokenRepository.withHttpOnlyFalse() + SameSite=Lax session cookie; Axios X-XSRF-TOKEN interceptor wired in Plan 04 |
| T-01-09 | Information disclosure | Session id leakage | mitigate | Cookie-only session tracking (tracking-modes=cookie, set in application.yml Plan 01); no JSESSIONID in URLs |
| T-01-10 | Information disclosure | Unauthenticated access to protected data | mitigate | anyRequest().authenticated(); authenticationEntryPoint returns 401 (no data) for unauthenticated API requests |
| T-01-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs in this plan (backend-only). npm legitimacy checkpoint applies to Plan 04. |
</threat_model>
