| HTTP client → /api/portfolio/{pnl,benchmark} | Untrusted request; session principal is the only trusted identity |
| service → Postgres bulk bars query | Internal; bounded result set; entities never serialized |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege (IDOR) | PortfolioController /pnl + /benchmark | mitigate | Both endpoints resolve portfolioId via the shared resolvePortfolioId(Authentication) helper — derived only from Authentication.getName(). No request param accepts a portfolio/user identifier. Unauthenticated → 401 (existing gate). |
| T-02-02 | Information Disclosure | service → JSON | mitigate | Returns PortfolioPnlDto/BenchmarkComparisonDto records only; entities never reach Jackson; loads inside @Transactional(readOnly=true). |
| T-02-03 | Denial of Service | findAllBySecurityIdsOrdered | accept | Bounded to ≤504×N rows per the seed; one JDBC round-trip; acceptable for a 3-user demo. |
| T-02-04 | Tampering (math correctness) | equity curve / daily change / rebasing | mitigate | Daily change uses curve[last]−curve[last−1] (off-by-one guarded); benchmark dates aligned by ORDER BY barDate ASC; both series rebased to exactly 100.0000 on day 0; every divide() rounds. Unit tests assert each invariant. |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages this phase (RESEARCH.md audit: none). No legitimacy checkpoint required. |
