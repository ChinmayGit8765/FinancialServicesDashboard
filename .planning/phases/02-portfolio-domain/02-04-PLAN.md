  TransactionRepository.findByPortfolioIdWithSecurity(Long, Pageable) -> Page<Transaction>  (txDate DESC, id DESC — display order)
  TransactionRepository.findByPortfolioIdChronological(Long) -> List<Transaction>  (txDate ASC, id ASC — for the running-cost scan)

From Plans 02–03 (reuse): PortfolioService (constructor-injected repos), PortfolioController.resolvePortfolioId(Authentication).

Entity getters: Transaction.getId()/getSecurity()/getTxDate()/getTxType()/getQuantity()/getPrice(); Security.getTicker()

Running average-cost algorithm (RESEARCH.md Pattern 1, exact):
  BUY:  runningCost += qty × price;  runningQty += qty
  SELL: avgCostNow = runningQty==0 ? 0 : runningCost / runningQty (scale 6);  runningCost -= sellQty × avgCostNow;  runningQty -= sellQty
  After each tx: avgCostAtThisPoint = runningQty==0 ? 0 : runningCost / runningQty (scale 6)  → this is runningCostBasis
  CRITICAL: SELL reduces basis by sellQty × avgCostNow, NEVER by sellQty × sellPrice.

Seed facts (alice): 5 tickers × (1 BUY at bar 50 + 1 SELL at bar 200) = 10 transactions. Each ticker's running cost basis after its proportional SELL equals the original BUY price (the position's avgCostBasis), per RESEARCH.md Pattern 1 known-seed note.

BigDecimal scale: runningCostBasis + price scale 6; quantity scale 4; tradeValue scale 2. Sort/scan by txDate ASC, id ASC (Pitfall 5). Every divide() passes (scale, RoundingMode.HALF_UP).

| Boundary | Description |
|----------|-------------|
| HTTP client → /api/portfolio/transactions | Untrusted request incl. page/size params; session principal is the only trusted identity |
| service → Postgres paginated + chronological queries | Internal; parameterized JPQL; entities never serialized |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege (IDOR) | PortfolioController /transactions | mitigate | portfolioId resolved via resolvePortfolioId(Authentication) only; page/size are the only request params and carry no identity. Unauthenticated → 401. |
| T-02-05 | Denial of Service | Pageable size param | mitigate | spring.data.web.pageable.max-page-size caps size; @PageableDefault sets size=20 — prevents ?size=10000 from materializing an unbounded result. |
| T-02-02 | Information Disclosure | service → JSON | mitigate | Returns Page<TransactionDto> — never Page<Transaction> (Pitfall 6); no lazy-load leakage of AppUser/passwordHash; loads inside @Transactional(readOnly=true). |
| T-02-04 | Tampering (math correctness) | running cost basis | mitigate | SELL reduces basis by sellQty × current avg cost (not sell price); scan ordered txDate ASC, id ASC (Pitfall 5); divide() rounds. Unit tests assert post-SELL basis == buyPrice. |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages this phase (RESEARCH.md audit: none). No legitimacy checkpoint required. |
