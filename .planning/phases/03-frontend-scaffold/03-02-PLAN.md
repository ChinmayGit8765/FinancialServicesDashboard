<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/portfolio/* | Authenticated cross-origin (proxied) reads carrying the session cookie |
| API 401 → SPA router | Expired/absent session triggers client-side redirect |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03 | Spoofing | portfolio fetch requests | mitigate | Reuse the global axios singleton (withCredentials + CSRF interceptor from api/auth.ts); do NOT re-register interceptors or set a base auth header in portfolio.ts (RESEARCH.md Pattern 6 / PATTERNS.md note). |
| T-03-04 | Denial of service | 401 redirect loop | mitigate | The 401 response interceptor explicitly excludes `/auth/me` and `/auth/login` URLs before calling router.push (RESEARCH.md Security Domain). |
| T-03-05 | Information disclosure | store error strings | mitigate | Error messages are generic ("Failed to load holdings"/"Session expired") — never echo raw server response bodies or stack traces into store state. |
| T-03-06 | Tampering | circular import (axios interceptor → router) | accept | Importing the router singleton in api/auth.ts is safe in a Vite SPA (module evaluated after createRouter); fallback `window.location.href='/login'` if a circular-import undefined is observed at build (RESEARCH.md Assumption A2). |
</threat_model>
