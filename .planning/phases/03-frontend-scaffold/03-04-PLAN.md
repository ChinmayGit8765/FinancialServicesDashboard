<interfaces>
<!-- DTO shapes (from Plan 02). BigDecimal → number; format via Plan 01 utils. -->
HoldingDto: { ticker, name, sector:string, quantity:number (may be fractional), avgCostBasis, currentPrice, currentMarketValue, portfolioWeight:number (0–1), unrealizedPnlAbs:number, unrealizedPnlPct:number (0–1 fraction, scale 6) }
TransactionDto: { txDate:string "2022-09-12", txType:'BUY'|'SELL', ticker:string, quantity:number, price:number, tradeValue:number, runningCostBasis:number }  (NO id field — authoritative shape, supersedes any RESEARCH.md "API Types Module" example that shows an `id` field or omits `tradeValue`)

format.ts (Plan 01) exports: formatCurrency, formatCurrencyCompact, formatPercent, formatSignedCurrency, formatSignedPercent, deltaClass('val-up'|'val-down'|'val-flat'), formatDate
NOTE: unrealizedPnlPct & portfolioWeight are 0–1 fractions → use formatPercent (which multiplies by 100). dailyChangePct/totalUnrealizedGainPct are also fractions. For SIGNED percent on a fraction, multiply by 100 before formatSignedPercent (which expects percent units), OR display via formatPercent for unsigned weight.

TransactionsTable emit contract: `defineEmits<{ 'page-change': [n: number] }>()` — the emit is named `page-change` (NOT `page`) to avoid colliding with the `page` prop. DashboardView (Plan 05) wires it via `@page-change`.

Component tests: use `mount` from @vue/test-utils for tables/cards (no ECharts → no ResizeObserver needed). createTestingPinia not required (these are prop-driven, no store access).
</interfaces>
