# Phase 3 — UI Design Contract: Frontend Scaffold

> Visual and interaction contract for the QuantLens Vue 3 dashboard.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
> Source-of-truth for gsd-planner and gsd-executor during Phase 3 implementation.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (scoped CSS per component; no utility framework) |
| Preset | not applicable |
| Component library | none (hand-authored Vue SFC components) |
| Icon library | none for Phase 3 (use Unicode/SVG inline symbols; Phosphor or Lucide may be added Phase 4+) |
| Font | System stack: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, sans-serif` (already set in App.vue global reset). Numeric columns use `ui-monospace, 'Cascadia Code', Consolas, monospace` for tabular figures. |

## Design Tokens

All tokens are CSS custom properties declared on `:root` in `frontend/src/style.css`
(replacing the current Vite scaffold values). Each component references `var(--token)`.

### Color Palette

```css
:root {
  /* --- Background Layers (deep-to-shallow) --- */
  --color-bg-base:      #0b0f1a;  /* page canvas; deepest layer */
  --color-bg-elevated:  #0f172a;  /* panels that sit on canvas (matches existing code) */
  --color-bg-surface:   #1e293b;  /* cards, table rows, chart containers */
  --color-bg-overlay:   #263248;  /* hover rows, selected state, tooltip bg */

  /* --- Border --- */
  --color-border:       #334155;  /* all card/table/input borders */
  --color-border-subtle:#1e293b;  /* divider lines inside panels */

  /* --- Text --- */
  --color-text-primary: #e2e8f0;  /* body copy, table values */
  --color-text-secondary:#94a3b8; /* labels, captions, secondary info */
  --color-text-muted:   #64748b;  /* placeholders, disabled, empty-state text */
  --color-text-inverse: #0b0f1a;  /* text on solid accent buttons */

  /* --- Accent (sky blue — established in Phase 1 code) --- */
  --color-accent:       #0ea5e9;  /* primary interactive: logo, focus rings, active nav */
  --color-accent-light: #38bdf8;  /* hover state on accent elements */
  --color-accent-subtle:#1e3a5f;  /* tinted background behind accent badges/chips */

  /* --- Semantic: P&L Up/Down --- */
  --color-up:           #22c55e;  /* positive P&L, gain delta, up arrows */
  --color-up-subtle:    rgba(34, 197, 94, 0.12);  /* tinted bg for positive KPI card */
  --color-down:         #ef4444;  /* negative P&L, loss delta, down arrows */
  --color-down-subtle:  rgba(239, 68, 68, 0.12);   /* tinted bg for negative KPI card */

  /* --- Semantic: Warning / Neutral Delta --- */
  --color-warn:         #f59e0b;  /* flat/unchanged delta, loading state accent */
  --color-warn-subtle:  rgba(245, 158, 11, 0.12);

  /* --- Semantic: Destructive (logout confirm, future delete) --- */
  --color-destructive:  #f87171;  /* destructive action text/border (matches existing logout hover) */
}
```

**60/30/10 split:**
- 60% Dominant: `--color-bg-base` + `--color-bg-elevated` — page canvas and panel backgrounds
- 30% Secondary: `--color-bg-surface` + `--color-bg-overlay` — cards, table rows, nav, tooltips
- 10% Accent: `--color-accent` / `--color-up` / `--color-down` — reserved exclusively for the elements listed in the Accent section below

**Accent reserved for (exhaustive list):**
- QuantLens logo text in the top bar
- Active persona button border and background in the switcher
- Focus ring on all focusable elements (`outline: 2px solid var(--color-accent)`)
- Hyperlinks and external reference text
- Positive P&L values and up-delta indicators (`--color-up`)
- Negative P&L values and down-delta indicators (`--color-down`)
- Loading spinner stroke
- Chart series: portfolio line (`--color-accent`), gain-fill (`--color-up`), loss-fill (`--color-down`)

**Not accent:** Table borders, section headings, secondary text, chart grid lines, scrollbars.

  --radius-md:   8px;   /* input fields, table cells with rounded variant, small cards */

## Spacing Scale

All spacing values are multiples of 4.

| Token | CSS Var | Value | Usage |
|-------|---------|-------|-------|
| xs | `--space-xs` | 4px | Icon-to-label gap, badge padding, row cell padding vertical |
| sm | `--space-sm` | 8px | Compact element gaps, button horizontal padding complement |
| md | `--space-md` | 16px | Default panel padding, form field gap, table cell padding horizontal |
| lg | `--space-lg` | 24px | Card internal padding, section spacing within panels |
| xl | `--space-xl` | 32px | Gap between grid rows, between KPI cards and chart row |
| 2xl | `--space-2xl` | 48px | Top-bar height (fixed), distance from top bar to first content row |
| 3xl | `--space-3xl` | 64px | Not used in Phase 3 |

**Exceptions:**
- Touch/click targets: minimum 44px height on all interactive controls (persona buttons, logout, table pagination) to meet WCAG 2.5.5.
- Top bar fixed height: exactly 48px content area + 1px border-bottom.
- Chart minimum height: 240px (panel), 320px (full-width equity curve).

## Typography

Font sizes in px; weights are 400 (regular) and 600 (semibold) only.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Display | 24px | 600 | 1.2 | system stack | Panel section headings, chart titles |
| Heading | 18px | 600 | 1.25 | system stack | KPI card primary values, table section labels |
| Body | 14px | 400 | 1.5 | system stack | Table body text, captions, general prose |
| Label | 11px | 600 | 1.3 | system stack | Column headers (uppercase + letter-spacing 0.06em), badge text, axis tick labels |
| Numeric | 14px | 400 | 1.4 | monospace | All currency/percent values in tables and KPI cards (`font-variant-numeric: tabular-nums`) |
| Numeric-large | 20px | 600 | 1.2 | monospace | KPI card primary metric number |

**Top-bar brand text:** 20px / weight 700 / `--color-accent`. This is the only weight-700 use in Phase 3.

**Rules:**
- Column headers: `font-size: 11px; font-weight: 600; text-transform: uppercase; letter-spacing: 0.06em; color: var(--color-text-muted)`.
- All monetary/percent columns must use `font-variant-numeric: tabular-nums; font-family: var(--font-mono)` so digits align vertically.
- No italic usage in Phase 3.

## Number Formatting

All formatting via `Intl.NumberFormat` in a shared `src/utils/format.ts` module.

| Value type | Format | Example | Color rule |
|------------|--------|---------|------------|
| Currency (large) | `$1,234,567.89` | USD, 2 decimal places, comma thousands | None (inherit) |
| Currency (compact) | `$1.23M` | compact notation above 1M | None |
| Percent | `12.34%` | 2 decimal places | None |
| Signed delta absolute | `+$4,567.00` / `-$1,234.00` | leading sign always shown | `--color-up` if positive, `--color-down` if negative |
| Signed delta percent | `+2.34%` / `-1.12%` | leading sign always shown | `--color-up` if positive, `--color-down` if negative |
| Quantity | `1,234` | integer, comma thousands | None |
| Date | `DD MMM YYYY` | `07 Jun 2026` | None |

Zero / flat delta: show `0.00%` in `--color-warn` (amber), not green or red.

A `<SignedValue>` Vue component wraps a value + sign-aware CSS class: `.val-up`, `.val-down`, `.val-flat`.

## Layout

### Grid Overview

Desktop-first. Top bar is `position: fixed; top: 0; width: 100%; z-index: 100`.
Content area begins at `padding-top: 48px` (top bar height).
Outer page padding: `0 24px` at desktop (≥1280px), `0 16px` at medium (≥768px).

Main content uses CSS Grid with a 12-column base, 24px gaps:
```
grid-template-columns: repeat(12, 1fr);
gap: var(--space-xl);  /* 32px */
```

## Components and States

Each component lives in `frontend/src/components/`. All accept a `loading` + `error` prop pattern; parent (DashboardView) drives these from the `portfolio` Pinia store.

### Top Bar (`TopBar.vue`)

Fixed, full-width, 48px height.

| Slot | Content |
|------|---------|
| Left | QuantLens wordmark (20px, weight 700, `--color-accent`) + optional subtitle "AI Portfolio Intelligence" (11px, `--color-text-muted`) |
| Center | Persona switcher: 3 pill buttons. Active persona: `border: 1px solid var(--color-accent); background: var(--color-accent-subtle); color: var(--color-text-primary)`. Inactive: `border: 1px solid var(--color-border); color: var(--color-text-secondary)`. Each pill: `padding: 6px 16px; border-radius: var(--radius-pill); font-size: 13px; font-weight: 600`. On click: calls `authStore.loginAs()` then triggers `portfolioStore.refreshAll()`. During switch: all pills disabled + spinner icon replaces active pill text. |
| Right | `@username` in `--color-text-secondary` (14px) + "Log out" button: transparent background, `border: 1px solid var(--color-border)`, `color: var(--color-text-secondary)`. On hover: `border-color: var(--color-destructive); color: var(--color-destructive)`. |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Focus rings | `outline: 2px solid var(--color-accent); outline-offset: 3px` on all `:focus-visible` elements. Never `outline: none` without a replacement. |
| Color contrast — body text | `--color-text-primary` (#e2e8f0) on `--color-bg-surface` (#1e293b): contrast ratio ~10.4:1. Passes WCAG AA and AAA. |
| Color contrast — muted text | `--color-text-secondary` (#94a3b8) on `--color-bg-surface` (#1e293b): contrast ratio ~4.7:1. Passes WCAG AA. |
| Color contrast — label/muted | `--color-text-muted` (#64748b) on `--color-bg-surface`: ratio ~3.1:1. AA for large text / UI components only. Use for non-critical labels only. |
| Semantic P&L | Never convey gain/loss by color alone. Always prefix signed delta with `+` or `-` character. Screen readers will read the sign. |
| Sortable table headers | `<th scope="col" aria-sort="ascending|descending|none">`. |
| Loading states | Shimmer skeletons must have `aria-busy="true"` on the container + `aria-label="Loading [panel name]"`. |
| Chart accessibility | Each `<v-chart>` wrapped in a `<figure>` with a `<figcaption>` containing a text summary of the chart data (e.g., "Portfolio value over time from Jan 2023 to Jun 2025. Starting value $1.0M, ending value $1.23M."). |
| Persona switcher | Group in `<nav aria-label="Persona switcher">`. Active persona: `aria-pressed="true"`. |
| Minimum touch target | 44×44px on all interactive controls. |
