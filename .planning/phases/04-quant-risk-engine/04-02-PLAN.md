<formulas>
<!-- From 04-RESEARCH.md — exact. -->
logReturns(curve): r[i-1] = Math.log(curve[i].value().doubleValue() / curve[i-1].value().doubleValue()) for i=1..n-1. 504 bars -> 503 returns.
Sharpe = (mean(excessReturns) / DescriptiveStatistics(returns).getStandardDeviation()) * Math.sqrt(252.0); excess[i] = returns[i] - factorRows.get(i+1).getRf().doubleValue(); if RF absent use 0.
AnnualizedVol = DescriptiveStatistics(returns).getStandardDeviation() * Math.sqrt(252.0).
MaxDrawdown: iterate curve tracking running peak; dd=(v-peak)/peak; return most-negative dd (in [-1,0]).
Beta = new Covariance().covariance(portfolioReturns, benchmarkReturns) / new DescriptiveStatistics(benchmarkReturns).getVariance().
Historical VaR%: -DescriptiveStatistics(returns).getPercentile(5.0)  (5th pct is negative -> positive loss).
Parametric VaR%: z*sigma - mean, z=1.645, sigma=getStandardDeviation(), mean=getMean().
VaR amount (BigDecimal): BigDecimal.valueOf(varPct * currentPortfolioValue).setScale(2, RoundingMode.HALF_UP); currentPortfolioValue = Σ qty × latestClose.
Guard: if returns.length < 252 throw IllegalArgumentException.
Correlation: build n×k matrix (rows=trading days, cols=securities) of aligned log returns; new PearsonsCorrelation(matrix).getCorrelationMatrix(); entry(i,j); diagonal=1.0; symmetric. tickers list ordered same as columns.
</formulas>
