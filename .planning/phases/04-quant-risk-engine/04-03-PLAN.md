<!-- From 04-RESEARCH.md — exact. -->
FF: portfolio log returns503 from equity curve. For i in 0..502: fr = factorRows.get(i+1) (ALIGNMENT — Pitfall 5); xMatrix[i] = {fr.getMktRf().doubleValue(), fr.getSmb().doubleValue(), fr.getHml().doubleValue()}; excess[i] = returns503[i] - fr.getRf().doubleValue().
reg.newSampleData(excess, xMatrix) — DO NOT add an intercept column (Hipparchus adds it; Pitfall 2). params = estimateRegressionParameters(); params.length == 4; params[0]=alpha(daily), [1]=betaMkt, [2]=betaSmb, [3]=betaHml. alphaAnnualized = params[0]*252. rSquared = calculateRSquared(). contribX = paramsX * mean(factorX) * 252.

ADF (per candidate pair Y,X): logPriceY/X[i] = Math.log(close[i].doubleValue()), 504 points. Step1: xCol[i][0]=logPriceX[i]; step1.newSampleData(logPriceY, xCol); hedgeRatio = params[1]; residuals = step1.estimateResiduals() (ADF runs on THIS — Pitfall 3). Step2 (adfN = residuals.length-2 = 502): adfY[i]=residuals[i+2]-residuals[i+1] (ΔS[t]); adfX[i][0]=residuals[i+1] (S[t-1]); adfX[i][1]=residuals[i+1]-residuals[i] (ΔS[t-1]); adfReg.newSampleData(adfY, adfX); delta=params[1]; seDelta=stdErrors[1]; tStat = delta/seDelta. Guard: if spread.length < 10 skip pair.
MacKinnon p-value (constant-only "c", n=1): if tau>2.74 return 1.0; if tau<-18.83 return 0.0; nd=NormalDistribution(0,1); if tau<=-1.61: lstar = 2.1659 + 1.4412*tau + 0.038269*tau*tau; else: lstar = 1.7339 + 0.93202*tau - 0.12745*tau*tau - 0.010368*tau*tau*tau; return nd.cumulativeProbability(lstar). NEVER use TDistribution for ADF.
Z-score: ds = DescriptiveStatistics(residuals); z = (residuals[last] - ds.getMean()) / ds.getStandardDeviation(). signal: z>2 -> "SHORT_Y_LONG_X"; z<-2 -> "LONG_Y_SHORT_X"; else "NEUTRAL".
Candidates: group holdings by Security.getSector(); same-sector C(n,2) pairs; cap at 20; report pairs with pValue < 0.05.
