  s3 = p95[i]-p75[i] (diff), areaStyle FAN_COLORS.bandOuter (band-2)
  s4 = p50 (absolute), NO stack, lineStyle FAN_COLORS.median width 2 (median line on top)
Pitfall 4: stacked series take DIFFERENCES, not absolute percentiles. ECharts canvas cannot read CSS vars at paint time → resolve via getComputedStyle once (FAN_COLORS), do not pass var(--...) strings into areaStyle.color.
