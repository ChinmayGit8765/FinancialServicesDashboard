## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form → POST /api/ai/key | The user's key crosses one-way client→server; must never persist client-side |
| store/component reactive state | Key must never land in Pinia state, localStorage, or Vue refs after submit |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-12 | Information Disclosure | error display | mitigate | Generic "Key rejected" copy only; never render provider/exception detail that could echo the key |
| T-06-13 | Spoofing/CSRF | POST/DELETE /api/ai/key | mitigate | axios singleton attaches X-XSRF-TOKEN + session cookie (auth.ts interceptor); backend endpoint authenticated |
