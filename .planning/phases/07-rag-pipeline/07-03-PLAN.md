| API response → DOM | answer + citation text rendered into the chat panel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-XSS | Tampering | ChatPanel message/citation rendering | mitigate | Render answer/citation text via Vue text interpolation ({{ }}) — never v-html — so any markup in retrieved/seeded content is escaped, not executed |
| T-07-LEAK | Information Disclosure | ai store / chat state | mitigate | Store never holds the API key (existing security invariant); sendMessage forwards only { message, conversationId }; messages live in reactive state only, never localStorage |
| T-07-SESSION | Information Disclosure | 401 handling | mitigate | sendMessage surfaces 'Session expired' on 401; the global api/auth.ts 401 interceptor handles redirect — no chat retry loop leaking state |
</threat_model>
